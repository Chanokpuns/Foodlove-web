Foodlove

A food web application developed as a project.

About the Project
Foodlove is a web application for ordering food online. 
Users can browse food menus, select food items, add them to a shopping cart, 
and calculate the total price. 


Features
\- Browse food menus
\- Select food items
\- Add items to shopping cart
\- Calculate total price

Tech Stack
\- \*\*Frontend:\*\* HTML, CSS, JavaScript, EJS
\- \*\*Backend:\*\* Node.js, Express.js
\- \*\*Tools:\*\* Git, GitHub, Figma
